# 浏览器验收

先执行 `bun run verify` 和 `cargo test --locked`，再检查：

1. 未登录访问 `/` 跳转到 `/login`；错误密码或 Turnstile 失败时无法登录。断网、超时和服务器异常显示对应原因，不误报为密码错误。
2. 正常登录进入面板，刷新保持登录，退出后再次访问需要登录。
3. 点击、拖拽和粘贴图片均可上传；批量任务最多同时处理 3 张，重复图片复用原地址。格式不支持或超过大小限制的文件点击“重试”仍被本地校验拒绝。
4. 图片列表支持搜索、加载更多、预览、复制链接和删除；重新上传已删除的图片获得新地址。
5. 公开图片地址无需认证；错误扩展名返回 404；非图片上传被拒绝。
6. 「设置」页中，Token 名称、生成按钮、生成结果和已有 Token 在同一张卡片内，位于油猴说明上方；明文只在创建时显示，复制正常，删除后立即失效。
7. 退出面板后，油猴仍能粘贴图片并插入前后换行的 `![粘贴图片](图片地址)`；在文本中间、空文本框、已有换行处以及连续/批量粘贴时，每张图片独占一行，光标停在图片后的新行。富文本编辑器和手动粘贴剪贴板内容也应保持前后换行；单行输入框只复制，不插入。普通文本粘贴及网页拖拽不受影响。
8. 油猴在图床自身页面不重复上传，浏览器控制台能看到失败原因。
9. 设置页可手动备份、查看时间和大小、下载 SQL，不展示 SHA-256；SQL 能恢复到空数据库。
10. 深浅色切换、窄屏布局和上传进度正常。

API Key 的管理权限限制、Cookie 伪造和过期、密钥轮换、SQL 特殊字符恢复、备份写入失败以及 Cron 均由集成测试覆盖。

11. 列表尚在加载时连续搜索和刷新，最终结果对应最新查询；清理已完成任务不影响计算 Hash 或查重中的上传。
12. 大图片上传后列表使用缩略图，打开预览仍显示原图；已有图片浏览后会补齐缩略图。确认浏览器不支持的格式仍可上传。
13. 修改 Rust、HTML、CSS 和共享 TypeScript，开发进程自动重建；连续保存不会并行启动多个构建。

自动测试验证了请求体真实流量限额、50 MiB 原图上传、条件缓存与 Range、缓存中图片删除后返回 404、R2/D1 故障恢复及历史备份保留。线上并发负载和不同浏览器解码行为需要实际环境验收。
