# 浏览器验收

先执行 `bun run verify` 和 `cargo test --locked`，再检查：

1. 未登录访问 `/` 跳转到 `/login`；错误密码或 Turnstile 失败时无法登录。
2. 正常登录进入面板，刷新保持登录，退出后再次访问需要登录。
3. 点击、拖拽和粘贴图片均可上传；批量任务最多同时处理 3 张，重复图片复用原地址。
4. 图片列表支持搜索、加载更多、预览、复制链接和删除；重新上传已删除的图片获得新地址。
5. 公开图片地址无需认证；错误扩展名返回 404；非图片上传被拒绝。
6. API Token 只在创建时显示明文，删除后立即失效。
7. 退出面板后，油猴仍能粘贴图片并插入 `![粘贴图片](图片地址)`；普通文本粘贴及网页拖拽不受影响。
8. 油猴在图床自身页面不重复上传，浏览器控制台能看到失败原因。
9. 设置页可手动备份、查看时间和校验值、下载 SQL；SQL 能恢复到空数据库。
10. 深浅色切换、窄屏布局和上传进度正常。

API Key 的管理权限限制、Cookie 伪造和过期、密钥轮换、SQL 特殊字符恢复、备份写入失败以及 Cron 均由集成测试覆盖。
